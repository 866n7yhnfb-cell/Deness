# Denessa 1.1 Online

Красивый морской интерфейс + настоящий realtime-чат через Cloudflare Workers и Durable Objects.

## Что внутри

- React + Vite
- адаптация под iPhone и компьютер
- список чатов
- профиль и имя пользователя
- онлайн-статус
- realtime WebSocket
- история последних 100 сообщений для каждой комнаты
- несколько отдельных комнат
- Cloudflare Durable Object для координации подключений

## Деплой

```bash
npm install
npm run deploy
```

В Cloudflare Workers конфигурация уже содержит Durable Object binding и миграцию.

## Важно

Это первая online-версия. Для следующего этапа можно добавить регистрацию, личные диалоги, поиск пользователей, фото/файлы, push-уведомления, голосовые сообщения и звонки.
